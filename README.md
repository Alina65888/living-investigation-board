# Living Project HQ

Браузерный штаб проектов: задачи, этапы, сроки, зависимости, риски, команда, календарь и живая 3D-доска.

## Возможности

- обзор текущих действий, рисков и согласований;
- список задач, Kanban, календарь и Timeline;
- проекты с этапами, контрольными точками, участниками и критическим путём;
- командная загрузка и задачи по исполнителям;
- зависимости и автоматическая блокировка следующих задач;
- 3D-доска с физическими нитями и упрощённый режим без WebGL;
- локальное сохранение, экспорт и импорт резервной копии;
- адаптивный интерфейс для компьютера и телефона.

## Публикация

https://alina65888.github.io/living-investigation-board/

GitHub Pages публикует содержимое каталога `docs` ветки `main`.

## Хранение данных

Рабочие данные сохраняются в IndexedDB текущего браузера. Для переноса на другое устройство используется JSON-резервная копия через меню «Данные».

## Разработка

Приложение в `docs` не требует сборки. Исходные файлы:

- `docs/app-v4.js` — проекты, задачи, фильтры и основные режимы;
- `docs/board-v8.js` — живая доска и связи;
- `docs/hq.js` — 3D-карта зависимостей;
- `docs/style.css`, `docs/v4.css`, `docs/visual-v8.css`, `docs/dashboard-v12.css` — интерфейс и адаптивность.

## Командная версия (v17)

Исходная доска сохранена: список, Kanban, календарь, проекты, этапы, критический путь и 3D-связи. Добавлены недельный план, обновлённый интерфейс, участники и очередь проблем.

- **GitHub Pages**: прежний адрес, локальные данные в прежней IndexedDB. Ничего автоматически не удаляется и не отправляется на сервер.
- **Командный режим**: кнопка открывает https://living-project-hq-alina.amullakaeva97.chatgpt.site — тот же код `docs`, общая база и вход через ChatGPT. В Sites развёрнута серверная часть с проверкой ролей.
- Администратор управляет проектами, людьми и задачами. Участник добавляет задачи себе, меняет статус, прогресс и отметки чек-листа своих задач; удалять не может.
- Сообщения о проблемах видят автор и администраторы; администратор отвечает и меняет статус.
- Сотруднику нужны назначенная роль по email аккаунта ChatGPT и доступ к приватному сайту в настройках Sites.
- Для переноса скачайте JSON через «Данные» в локальной версии, затем импортируйте в командной. Импорт заменяет общие проекты и задачи; сначала скачайте резервную копию. Участники и проблемы хранятся отдельно.
- При конфликте одновременных изменений сайт не перезаписывает более новую версию: предлагает скачать свою копию и обновить общую базу.
- Telegram пока не подключён. Раздел «Подключения» описывает следующий этап без имитации работающего бота.

`docs/workspace-store.js` — общий контракт хранения; `docs/team-ui.js` — недельный план, команда и проблемы; `docs/team-v17.css` — новое оформление. Сервер принимает только авторизованные запросы; выбор роли в браузере не даёт прав.
