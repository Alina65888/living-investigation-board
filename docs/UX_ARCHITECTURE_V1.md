# Living Project HQ — UX architecture v1

## Главная идея
Система должна отвечать не на вопрос «где мои карточки?», а на вопросы:

1. Что сейчас важно?
2. Где риск?
3. Что зависит от меня?
4. Что нужно сделать дальше?

---

## Главная навигация

### 1. Обзор (Home)
Первый экран после входа.

Блоки:
- Сегодня: задачи и решения на день.
- Риски: просрочки, блокеры, ожидания.
- Проекты: состояние крупных направлений.
- Команда: загрузка людей.

Пользователь за 10 секунд понимает ситуацию.

---

## Режимы просмотра

### Проекты
Для руководителя проекта.

Структура:
```
Проект
 ├── Цель
 ├── Этапы
 │    ├── Задачи
 │    └── Зависимости
 ├── Риски
 └── Следующее действие
```

### Люди
Для управления командой.

Показывает:
- задачи человека;
- перегруз;
- ожидания от других;
- просрочки.

### Связи
Граф зависимостей.

Используется для ответа:
«Почему задача остановилась?»

---

## Карточка проекта

Верх:
- название;
- владелец;
- срок;
- прогресс;
- уровень риска.

Ниже:

1. Цель проекта
2. Дорожная карта
3. Задачи
4. Участники
5. Решения и договоренности
6. История изменений

---

## Карточка задачи

Задача — это не просто название.

Обязательные поля:
- результат («что должно быть готово»);
- ответственный;
- срок;
- зависимость;
- следующий шаг.

Статусы:
- Запланировано
- В работе
- Ждем решения
- Заблокировано
- Готово
