# Google Диск — v63

## Однократная настройка

Google Cloud project: `mant-514113`. Включить Google Drive API. OAuth client: Web application.

- JavaScript origin: `https://zadachimantckd.ru`
- Redirect URI: `https://zadachimantckd.ru/api/google-drive-callback.php`
- Client ID уже задан в коде (это публичный идентификатор).
- Audience: External; добавить Google-аккаунт с правом редактора папки МАНТ в Test users.
- Data Access: `https://www.googleapis.com/auth/drive`. Это широкий, restricted scope: Google разрешает доступ ко всему Диску. Приложение ограничивает операции корневой папкой МАНТ и проверяет родителей каждой целевой папки при привязке и загрузке. Такой scope нужен для доступа по ссылкам к существующему дереву папок без выбора каждого файла в Picker. Не утверждайте, что разрешение Google ограничено одной папкой.

На хостинге, через файловый менеджер, скопировать `api/google-drive.sample.php` в `api/google-drive.local.php`. Вставить Client secret вместо заглушки. Секрет не отправлять в чат, не коммитить, не помещать в docs, не включать в артефакты GitHub Actions. Альтернатива — серверная переменная `GOOGLE_DRIVE_CLIENT_SECRET`. Нужны PHP cURL и OpenSSL.

`google-drive.local.php` исключён из Git и сборки. Обычная FTP-публикация его не создаёт и не обновляет. Полная очистка хостинга может удалить локальную конфигурацию и пользовательские данные: не запускайте full_upload без резервной копии. `api/.htaccess` блокирует прямое чтение настроек; основной роутер не обслуживает эти файлы. При Nginx настройте аналогичный запрет. Никогда не раздавайте PHP как текст.

После публикации: Документы → Google Диск → Подключить Google Диск. Войти аккаунтом с доступом редактора к общей папке. Проверяется возможность добавлять файлы в корневую папку. Токены зашифрованы AES-256-GCM с ключом на основе Client secret и хранятся в отдельной таблице `google_drive_state`; в данные карточек, ответы API и браузер они не попадают. При смене секрета подключить Google заново.

## Привязка папок

Корень МАНТ: `1e_2DfFV0jgWdwM0SIlghmu3w0IorX2qB`.

В окне Google Диска выбрать проект МАНТ, год и вставить ссылку на папку внутри корня. Для Жемчужины мира выбрать 2026 и `https://drive.google.com/drive/folders/1HK-YpKH_OWxnqHJt8dwfJKcp9ozOZYRh`. Сайт проверит фактическое расположение; оно ещё не проверено в живом аккаунте. Ярлыки не считаются вложенными папками. Для другого расположения сначала согласуйте нужный корень, не перемещайте пользовательские файлы автоматически.

Привязки сохраняются отдельно от карточек. Удаление привязки/отключение не удаляет файлы. Отключение удаляет локальные токены; разрешение можно отозвать в настройках безопасности Google-аккаунта.

## Поведение

При скачивании договора, акта, счёта, УПД, ПП, сметы или реестра отправляется копия в привязанную папку проекта соответствующего года. Нужна открытая страница до завершения отправки. Изменение карточки без формирования файла не создаёт документ. Ранее созданные файлы автоматически не выгружаются.

Одинаковые имя/содержимое/папка повторно используют созданный этим приложением файл по appProperties.hqDigest. Изменённый документ создаётся отдельным файлом с тем же именем, предыдущий не перезаписывается. Ошибка Google не отменяет локальное скачивание и показывается отдельно; повторное скачивание повторит попытку. Нет фоновой очереди, нет автоматического импорта или синхронизации смет, нет удаления файлов. Обычный участник команды не имеет доступа к API Google Диска.

В режиме Testing refresh token обычно истекает через 7 дней. Для постоянной работы потребуется перевод OAuth приложения в Production и выполнение применимых требований Google к restricted scope (проверка приложения/доступа в зависимости от использования). До этого переподключаться по сообщению сайта. Статус «подключён» означает наличие сохранённого разрешения; актуальность прав проверяется при операции.

## Проверка перед использованием

1. Участник не может получить статус/начать OAuth/привязать папку/отправить файл.
2. Администратор подключается; другой аккаунт без прав на корень отклоняется.
3. Папка вне МАНТ отклоняется, выбранная вложенная папка принимается.
4. Тестовый документ появляется в ожидаемой папке; повтор не создаёт дубликат; изменение создаёт отдельный файл.
5. После отзыва доступа локальное скачивание продолжает работать и показывает ошибку отправки.
6. Сверить существующие карточки и резервную копию: интеграция не изменяет таблицы docs/workspace.
